# Little Dragons 2026

In 2012 I built **Little Dragons**, an Android game, as my Bachelor thesis. The original code is gone.
For a tutorials.eu video, Claude rebuilt the game from one old YouTube video, then I gave it one sentence: *"Make it ten times better."*

This repo contains both results:

- `2012-copy/` – Claude's rebuild of the 2012 game (a copy, not the original app)
- `2026/` – the new version: hatching dragons, three modes (Classic, Zen, Boss Rush) and a boss fight

## Play it

- **In the browser:** download the repo and open `2026/index.html` (or `2012-copy/index.html`).
- **On Android:** download `LittleDragons2026.apk` from the [Releases](../../releases) page and install it (you have to allow installs from unknown sources). It is a debug-signed test build.

Built with AI by Claude, directed by Denis Panjuta / tutorials.eu.
